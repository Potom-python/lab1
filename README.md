# Лабораторная работа №1: Консольный калькулятор и конвертер единиц

Проект представляет собой консольный инструментарий (CLI-утилиту), объединяющий калькулятор математических выражений произвольной длины и конвертер физических величин. 

### 🌟 Ключевая особенность архитектуры
Вычислительное ядро (`calculator.py`, `converter.py`, `tokenizator.py`) полностью **изолировано от интерфейса командной строки** (`__main__.py`). Внутри модулей ядра отсутствуют встроенные функции `input()` и `print()`.

---

## 🛠 Технологический стек и реализация

* **Язык программирования:** Python 3.12+
* **Высокая точность (Decimal):** Вместо стандартного типа `float` используется встроенный модуль `decimal`. Это исключает накопление аппаратных ошибок округления двоичной системы (например, выражение `0.1 + 0.2` возвращает строго `0.3`).
* **Токенизатор:** Построен на базе регулярных выражений (модуль `re`). Распознает числа, бинарные операторы, а также контекстно отделяет унарные знаки `+` и `-` от бинарных операторов.
* **Математический движок:** Вычисления реализованы через **Обратную польскую нотацию (RPN)**. Входящие токены перестраиваются в постфиксную форму с помощью словаря приоритетов операций, после чего вычисляются на базе классического стекового алгоритма.
* **Конвертер величин:** Реализован по принципу единой базовой единицы для каждой физической группы: * *Масса (База — грамм `g`):* Коэффициенты для перевода (`g` = 1, `kg` = 1000) хранятся в словаре `Decimal` объектов. Перевод осуществляется приведением исходного значения к базовой единице с последующим делением на коэффициент целевой. * *Длина (База — миллиметр `mm`):* Коэффициенты рассчитываются строго относительно миллиметра (`mm` = 1, `cm` = 10, `m` = 1000, `km` = 1000000). * *Температура (База — Цельсий `C`):* Перевод между шкалами Кельвина (`K`), Фаренгейта (`F`) и Цельсия (`C`) реализован через явные математические формулы пересчета, встроенные в логику условий. Перед конвертацией проверяется граничное условие физически невозможных температур (ниже Абсолютного нуля) для каждой шкалы отдельно.
* **Автоматические тесты (Pytest):** Покрывают 100% функционала: позитивные сценарии, негативные сценарии (граничные случаи) и интеграционные тесты CLI с использованием фикстур `monkeypatch` (подмена терминального ввода) и `capsys` (перехват консольного вывода).
* **Читаемость:** Код оформлен в соответствии со стандартами PEP 8 и снабжен аннотациями типов для всех ключевых функций.

## 🚀 Инструкция по запуску

Программа запускается из корневой директории как модуль Python:

### 1. Режим калькулятора (`calc`)
Поддерживает вычисления с пробелами, унарными знаками, вещественными числами и строгим приоритетом (`*`, `/` старше `+`, `-`).
```bash
python -m src.toolkit calc "2 + 3 * 4.5"
python -m src.toolkit calc "2+3/3*5+1"
python -m src.toolkit calc "-2 * -3"
python -m src.toolkit calc -2 * 3 + 1
```

### 2. Режим конвертера (`convert`)
Поддерживает три категории величин (регистр букв значения не имеет):
* **Масса:** `g`, `kg` (базовая единица — грамм)
* **Длина:** `mm`, `cm`, `m`, `km` (базовая единица — миллиметр)
* **Температура:** `C`, `F`, `K` (с автоматическим пересчетом формул)
```bash
python -m src.toolkit convert 1.5 --from kg --to g
python -m src.toolkit convert 100 --from c --to F
```

### 3. Информация о работе программы (`--help`)
```bash
python -m src.toolkit --help
```

## ⚠️ Коды возврата (Exit Codes) и обработка ошибок

Для надежной интеграции с системными скриптами утилита строго разграничивает коды завершения:
* **Код `0`:** Успешное выполнение вычислений / конвертации или вызов справки `--help`.
* **Код `2`:** Любая ошибка в процессе работы. Все сообщения выводятся строго в стандартный поток ошибок (`sys.stderr`), предотвращая загрязнение основного вывода.

**Перехватываемые исключения (Код 2):**
* Деление на ноль (`5 / 0`) -> `ValueError`
* Слишком много операторов подряд (`5 * * 3`) -> `ConsecutiveOperatorsError`
* Температура ниже Абсолютного нуля (`-300 C`) -> `AbsoluteZeroError`
* Попытка перевести несовместимые единицы (`10 kg` в `m`) -> `ValueError`
