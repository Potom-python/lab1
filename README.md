# Лабораторная работа 1 - калькулятор и конвертер величин

Консольная утилита на Python: считает арифметические выражения и переводит
величины (длину, массу, температуру) из одних единиц в другие.

## Установка и запуск
Чтобы репозиторий появился у вас на компьютере нужно ввести в командной строке (в той папке, в которой хотите, чтобы лежал репозиторий):
```bash
git clone https://github.com/Potom-python/lab1
```

Сначала нужно ввести команду:

```bash
pip install -e .
```

После этого команда доступна как модуль:

```bash
python -m toolkit calc "2 + 3 * 4"
python -m toolkit convert 1.5 --from kg --to g
python -m toolkit --help
```

## Калькулятор

Поддерживает `+`, `-`, `*`, `/`, целые и вещественные числа, унарные `+`/`-`
перед числом и пробелы в любом месте выражения. Приоритет операций
соблюдается как обычно `*` и `/` считаются раньше `+` и `-`.

```bash
python -m toolkit calc "2 + 3 * 4"      # 14
python -m toolkit calc "10 / 4"         # 2.5
python -m toolkit calc "-2 * -3"        # 6
```

Выражение можно передать и без кавычек - тогда argparse сам соберёт все
аргументы после calc в одну строку:

```bash
python -m toolkit calc -2 "*" 3 + 1
```

Все вычисления идут через `decimal.Decimal`, а не `float`, потому что `float` в Python не может точно представить многие десятичные
дроби (0.1 + 0.2 в обычном `float` даёт 0.30000000000000004). Точность ограничена 10 значащими цифрами
(`getcontext().prec = 10`), округление в большую сторону (`ROUND_HALF_UP`).

Как это устроено внутри: сначала выражение разбивается на токены
(`tokenizator.py`), потом токены переводятся в обратную польскую запись
через алгоритм сортировочной станции (`calculator.py`, `pars_to_rpn()`), и
только после этого RPN считается через стек (`calculate()`). Скобки пока не
поддерживаются.

## Конвертер

Единицы разбиты на три несовместимые между собой группы:

| Группа      | Единицы               |
| ----------- | --------------------- |
| Масса       | `g`, `kg`             |
| Длина       | `mm`, `cm`, `m`, `km` |
| Температура | `C`, `F`, `K`         |
Регистр не важен. Перевод между разными
группами запрещён, как и температура ниже абсолютного нуля.

```bash
python -m toolkit convert 1000 --from mm --to m     # 1
python -m toolkit convert 0 --from c --to f         # 32
python -m toolkit convert -300 --from c --to k      # ошибка, ниже абсолютного нуля
python -m toolkit convert 10 --from kg --to m       # ошибка, разные группы
```

Коэффициенты для массы и длины лежат отдельным файлом -
`src/toolkit/convert_coef.json`, конвертер подгружает их оттуда, а не
хранит в коде. Температура считается через формулы (Цельсий как база),
потому что коэффициентами такой перевод не сделать.

## Ошибки и коды возврата

Успешная команда завершается кодом `0`. Любая ошибка - что в выражении,
что в аргументах командной строки - выводится в `stderr` и даёт код `2`.
Ошибки самого разбора аргументов (не хватает `--from`, неизвестная
подкоманда) обрабатывает `argparse`; ошибки внутри вычислений (деление на
ноль, неизвестная единица, некорректный символ и т. п.) - свои исключения
(`ValueError`, `SyntaxError`, `AbsoluteZeroError` из `errors.py`), которые
ловятся один раз в `__main__.py`.

Вычислительное ядро (`tokenizator.py`, `calculator.py`, `converter.py`) не знает про
`input()`/`print()` - всем выводом занимается только `__main__.py`.
